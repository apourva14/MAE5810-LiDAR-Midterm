LiDAR dependencies in one navigation task

Use the same cluttered navigation problem to connect sensor measurements to robot behavior. Fixed-pose replay isolates measurement changes; separate closed-loop runs show their consequences.

1. Sensor measurements at identical robot poses

The denominator changes through the chain: emitted target intersections → nearest visible target echoes → range-eligible echoes → noisy detections. Detection probability uses eligible echoes; range error uses detected returns. These statistics are conditioned on the designated target.

Model predictions and interpretation

For a diffuse beam-filling target, power follows P ∝ ρ cos(θ) r⁻² exp(−2κr). Range, reflectance, incidence, atmospheric attenuation, FOV, occlusion, and noise act at different stages. A geometry change can also change which target surface is sampled.

Black dashed curves are analytical expectations evaluated using each recorded eligible echo. Observed probability is detections / eligible echoes; expected probability is the sum of detection probabilities / the same eligible echoes. Range RMS is conditional on detection. A pose with no eligible echo has no defined detection probability, and a pose with no detections has no range-error statistic.
